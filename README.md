Football Career
Браузерная футбольная карьера. Игра открывается в Safari на телефоне, отдельный Wi-Fi с компьютером не нужен.

Три режима:

игрок — тренировки, энергия, матчи, голы, трансферы по лигам
клуб — состав, бюджет, уважение, лестница лиг
онлайн-батл — игра с другом по коду
Есть аукцион легенд чемпионатов мира с 1994 по 2026: Месси, Зидан, Роналду, Этоо, Мане и другие. Схема 4-3-3, по одному игроку, с перекруткой.

После README ещё одно: файлы игры сейчас лежат внутри папки «Футбольная карьера». Для сайта на GitHub они должны быть в корне, не в папке. Залей туда index.html, style.css, game.js, audio.js — без serve.py.
